# tread

写真作品「tread」に関連する、車輪の取得位置を閲覧するためのウェブマップです。

## Features

- 地図上のピンから車輪番号と写真を表示
- 車輪番号一覧から取得位置へ移動
- スマートフォンでの閲覧に対応

## Website

https://tomonariutsuno.github.io/tread-location/

## Technology

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
